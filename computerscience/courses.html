Computer Science Courses

COSC 1301 - Introduction to Computing
This course provides an overview of computer systems, hardware, operating systems, the Internet, and common application software. It also introduces the history and use of computers in society.
COSC 1320 - C Programming
This course introduces structured programming using the C programming language. Topics include data types, control structures, functions, arrays, pointers, files, testing, and debugging.
COSC 1315 - Introduction to Computer Programming
This course introduces computer programming and problem solving. Students learn program design, development, testing, implementation, documentation, structured techniques, and algorithms.
